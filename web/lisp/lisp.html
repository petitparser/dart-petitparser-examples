### About this Interpreter

This Lisp dialect is built with **PetitParser** and features a clean AST-based evaluator:

* **S-Expression Grammar**: Tokenizes symbols, numbers, strings, and quoted lists with zero regex.
* **Lexical Closures**: Lambdas capture their enclosing environment frames dynamically.
* **Native Extensibility**: Standard library primitives and math operators map directly to Dart functions.

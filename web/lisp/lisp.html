### What makes this interpreter special?

This interactive environment demonstrates how PetitParser transforms raw textual syntax into an active, functional programming language runtime:

* **Scannerless S-Expressions**: Parses symbols, numbers, strings, and quoted lists directly without a standalone lexical analyzer.
* **First-Class Closures**: Functions (`lambda`) capture their defining lexical environment frame, supporting lexical scoping, higher-order functions (`map`), and stateful closures (`counter`).
* **Seamless Host Interop**: Standard library primitives, math operators, and I/O streams bind directly to native Dart closures without bridging overhead.

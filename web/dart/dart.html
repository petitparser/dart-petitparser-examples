## About Dart Grammar This visualizer parses Dart 3+ source code into strongly-typed Abstract Syntax Trees using PetitParser combinators. ### Key Parser Features - **Modern Dart 3 Syntax**: Supports structural pattern matching (object, list, map, record, relational, and logical patterns), destructuring assignments, switch expressions, and class modifiers (`sealed`, `base`, `interface`, `final`). - **Scannerless Parsing**: Parses comments, whitespace, string interpolations, and ambiguous tokens directly in a unified combinator definition. - **Typed AST Hierarchy**: Constructs typed AST node classes with source offsets and visitor traversal support. - **Modular Productions**: Allows parsing full compilation units as well as individual statements, expressions, patterns, or types.
Built with PetitParser.

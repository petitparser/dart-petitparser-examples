### What makes this grammar special? This visualizer implements the complete **modern Dart 3+ language specification** purely as composable Dart parser combinators with zero external code generation: * **Modern Dart 3 Syntax**: Full support for structural pattern matching (object, list, map, record, relational, and logical patterns), destructuring assignments, switch expressions, and class modifiers (`sealed`, `base`, `interface`, `final`). * **Scannerless PEG Grammar**: Unlike traditional LALR or lexer-dependent compilers, the entire Dart syntax (including string interpolation, raw strings, and disambiguation of generics vs. relational operators) is parsed in a unified, backtracking combinator tree. * **Strongly Typed AST**: Directly constructs immutable, typed AST node classes with source offsets and visitor pattern traversal.
Built with PetitParser.

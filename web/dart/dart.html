### Grammar Features This visualizer demonstrates PetitParser's full implementation of the **Dart programming language**: * **Dart 3 Syntax**: Records, pattern matching (object, list, map, record, relational, and logical patterns), switch expressions, and class modifiers (`sealed`, `base`, `interface`, `final`). * **Typed AST Generation**: Every construct is mapped into immutable AST node records that can be walked with visitor patterns or inspected in debuggers.

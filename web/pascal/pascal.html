## About Pascal Grammar Pascal is a historically imperative and procedural language designed by Niklaus Wirth to encourage structured programming and rigorous data structuring. ### What Makes This Parser Special? - **Apple Pascal Standard Compliance**: Faithfully implements the syntax specified in the 1978 Apple Pascal Reference Manual (derived from UCSD Pascal). - **Comprehensive Scoping & Declarations**: Fully parses constants, type aliases, structured records (`record ... end`), enumerations, subranges, arrays, pointer types, variable declarations, and nested procedures/functions. - **Dual Comment Conventions**: Seamlessly handles both curly-brace comments (`{ ... }`) and alternate multi-character delimiter comments (`(* ... *)`), including nested lexical whitespace skipping. - **Production Modularity**: Designed using PetitParser's `GrammarDefinition` pattern, enabling direct parsing from individual isolated productions (`program`, `block`, `statement`, `expression`, `type`).

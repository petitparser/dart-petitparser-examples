### Indentation & PEG Python's significant whitespace is traditionally tricky for pure PEG parsers. PetitParser handles this cleanly: * **Indentation Stack**: Tracks indentation levels during lexical tokenization to emit virtual `INDENT`, `DEDENT`, and `NEWLINE` tokens. * **Modern Features**: Full support for structural pattern matching (`match` / `case`), type parameter syntax (`[T]`), and walrus assignment expressions (`:=`).

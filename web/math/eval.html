### About this Evaluator Built using PetitParser's `ExpressionBuilder` combinator: * **Operator Precedence**: Correctly models left- and right-associative operators (`+`, `-`, `*`, `/`, `^`, `%`). * **Dynamic Functions**: Supports built-in functions such as `sin`, `cos`, `tan`, `sqrt`, `log`, `abs`, and constants like `pi` and `e`. * **Tree Representation**: The parser builds an abstract expression tree before evaluating it against variable environments.

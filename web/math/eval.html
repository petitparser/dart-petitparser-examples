About Math Evaluator

This interactive evaluator parses mathematical expressions into an abstract syntax tree (**AST**) and computes numerical results in real time. ### What Makes This Parser Special? - **ExpressionBuilder Combinator**: Demonstrates PetitParser's `ExpressionBuilder`, a higher-level combinator that simplifies defining complex operator precedence and associativity rules without manual grammar factoring. - **Associativity & Precedence Levels**: Seamlessly differentiates left-associative operations (addition, subtraction, multiplication, division) from right-associative operators (exponentiation `^`). - **Dynamic Function Application**: Parses arbitrary named multi-argument function calls (`sin(x)`, `atan2(y, x)`, `sqrt(x)`) and mathematical constants (`pi`, `e`). - **Separation of AST and Evaluation**: Rather than computing results during parsing, it builds an immutable `Expression` AST hierarchy that can be evaluated against arbitrary variable environments.
Built with PetitParser.

## About Math Plotter This real-time plotter evaluates mathematical functions of one spatial variable (_x_) and dynamic time (_t_) directly onto an HTML5 canvas at 30 FPS. ### What Makes This Example Special? - **Real-Time Dynamic Evaluation**: The formula is parsed once into an abstract expression tree. Every rendering frame, that parsed tree is repeatedly evaluated across the entire horizontal canvas pixel domain with incremented time parameters. - **Resilient Asynchronous Error Handling**: If syntax or domain errors occur while editing the formula, the rendering loop degrades gracefully without breaking canvas animation state or throwing unhandled exceptions. - **Responsive High-DPI Canvas Rendering**: Dynamically adapts to device pixel ratios and window resizing events while maintaining crisp vector rendering.

## About Math Plotter This real-time plotter evaluates mathematical functions of one spatial variable (_x_) and time (_t_) directly onto an HTML5 canvas at 30 FPS. ### Key Features - **Parsed Expression Tree**: The mathematical expression is parsed once into an AST, then repeatedly evaluated across horizontal canvas pixel columns for each animation frame. - **Error Handling**: Syntactic and evaluation errors display an inline warning without interrupting the animation loop. - **Canvas Rendering**: Adapts to device pixel ratios and window resizing events to maintain crisp graph lines.
Built with PetitParser.

Math Plotter

Real-time expression parser that animates dynamic multi-variable formulas on an HTML5 canvas.

Website Source

Presets

Function ft(x)

Graph Viewport

Parameters: x ∈ [-5, 5], y ∈ [-2.5, 2.5], t is incremented each animation frame.

### How it Works * The mathematical formula is compiled into an executable expression tree using PetitParser. * Every animation frame (30 FPS), the tree is evaluated over the horizontal pixel resolution for varying `t` time steps. * Parsing errors are detected dynamically as you type without interrupting the rendering loop.
Built with PetitParser.

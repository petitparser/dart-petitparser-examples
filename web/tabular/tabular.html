About Tabular Text Parser

Tabular text formats like Comma-Separated Values (CSV) and Tab-Separated Values (TSV) are ubiquitously used for structured data interchange. ### What Makes This Parser Special? - **Configurable `TabularDefinition`**: Built as a parameterized grammar where field delimiters (`,`, `\t`, `;`), quote characters (`"`), and end-of-line sequences can be customized without rewriting parsing logic. - **Robust RFC 4180 Compliance**: Correctly parses complex quoting edge cases, including multiline cell content, embedded commas, leading/trailing whitespace inside quotes, and escaped quotes (`""`). - **Resilient Row Termination**: Gracefully tolerates mixed Windows (`\r\n`) and Unix (`\n`) newline conventions as well as optional trailing newlines.
Built with PetitParser.

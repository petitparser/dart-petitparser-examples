### About this Parser The **Tabular Definition** handles real-world CSV/TSV edge cases using PetitParser: * **Quoted Cells**: Supports values enclosed in double quotes containing embedded line breaks and delimiters. * **Escaped Quotes**: Properly parses escaped double quotes (`""`). * **Format Flexibility**: Easily parameterized for alternate delimiters, custom quote characters, and row terminators.

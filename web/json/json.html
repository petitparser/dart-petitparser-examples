### About this Parser The **PetitParser JSON grammar** models the complete [ECMA-404 JSON standard](https://www.json.org/) directly as composable Dart parser combinators. * **Grammar Definition**: Defined in [`JsonDefinition`](https://github.com/petitparser/dart-petitparser-examples/blob/main/lib/json.dart) using modular rules for objects, arrays, strings with escape sequences, numbers, and boolean/null tokens. * **Pure Dart Execution**: Unlike `dart:convert` (which delegates to optimized C++/native runtime primitives), PetitParser operates completely within Dart bytecode or WebAssembly, enabling custom AST transformations and syntax extensions.

### What makes this parser special? The **PetitParser JSON grammar** implements the complete [ECMA-404 JSON standard](https://www.json.org/) as composable parser combinators: * **Pure Dart Implementation**: Unlike `dart:convert` (which delegates to proprietary C++ runtime primitives), PetitParser runs entirely in Dart bytecode or WebAssembly, making it fully portable, inspectable, and debuggable. * **Extensible Architecture**: Serves as a modular foundation that can easily be extended into non-standard variants such as JSON5, JSON with comments (JSONC), trailing commas, or custom unquoted keys. * **Live Head-to-Head Benchmark**: Measures real-time execution speeds side-by-side with native platform decoders across varying structural loads.

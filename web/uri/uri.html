## About URI Parser Uniform Resource Identifiers (URIs) provide a standard, extensible mechanism for identifying resources on the internet or private networks. ### What Makes This Parser Special? - **Strict RFC 3986 Specification Compliance**: Implements the official ABNF grammar for URIs using PetitParser's combinator hierarchy, handling edge-case nuances that generic regular expressions fail on. - **Full Hierarchical Decomposition**: Dissects every structural component: scheme, authority (sub-parsing optional username, password, hostname, IPv6 host brackets, and port), hierarchical path segments, query strings (with decoded key-value parameters), and fragment identifiers. - **Percent-Encoding & Character Classes**: Reliably identifies and isolates pct-encoded octets (`%HH`), sub-delimiters, and unreserved character classes according to specification constraints.

### About this Parser Implements full [RFC 3986 Uniform Resource Identifier](https://www.rfc-editor.org/rfc/rfc3986) grammar decomposition using PetitParser combinators: * **Hierarchical Deconstruction**: Extracts scheme, authority (userinfo, host, port), path segments, query parameters, and fragment identifier. * **Component Validation**: Performs character set checking for percent-encoded escapes and path normalization rules.
Built with PetitParser.

### About this Parser Powered by `package:xml` built on PetitParser: * **Event-based Streaming (SAX)**: Emits high-performance tokens (`XmlEvent`) with character source positions. * **DOM Construction**: Generates typed trees (`XmlDocument`, `XmlElement`, `XmlAttribute`, `XmlText`). * **XPath 1.0 Support**: Evaluates axes, predicates, and node tests with live DOM element highlighting.

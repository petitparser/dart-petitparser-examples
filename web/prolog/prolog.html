## About Prolog Interpreter Prolog is a declarative logic programming language where computation is carried out by posing queries over a knowledge base of facts and inference rules. ### What Makes This Parser & Engine Special? - **First-Order Horn Clause Syntax**: Parses rules (`Head :- Body1, Body2.`), ground facts (`fact(a, b).`), logic variables (`X`, `_`), numbers, and recursive compound terms. - **SLD Resolution with Backtracking**: Implements full Selective Linear Definite clause resolution with automated search and backtracking to discover all valid variable bindings satisfying a goal. - **Syntactic Term Unification**: Matches terms structurally while propagating variable substitution environments across rule invocations. - **Pure Dart Inference Engine**: Both the parser and the full deductive inference machine run natively in the browser without external WebAssembly or C-based Prolog runtimes.

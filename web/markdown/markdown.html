### What makes this parser special? This parser implements both standard **CommonMark 0.31.2** and **GitHub Flavored Markdown (GFM)** without a separate tokenizer: * **Scannerless PEG Architecture**: Standard markdown engines employ complicated state machines and lexers. PetitParser parses block structures (headings, blockquotes, lists, tables) and recursive inlines (emphasis, autolinks, code spans, strikethrough) within a single combinator framework. * **Live Syntax Highlighting & AST**: The same grammar powers real-time in-editor syntax highlighting, strongly-typed AST tree generation, and standards-compliant HTML output. * **GFM Extensions**: Directly parses advanced features including GFM tables with column alignments and task list items (`[x]`).

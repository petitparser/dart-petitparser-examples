# Changelog

## 7.2.0 (Unpublished)

- Update BibTeX parsing (`parseEntries`, `parseStream`, `parseStreamChunks`) to use the generic streaming and iteration infrastructure in `package:petitparser/stream.dart`.

## 7.1.0

- Update to Dart 3.13 and PetitParser 7.1.
- Added CommonMark and GitHub Flavored Markdown (GFM) grammar, AST model, HTML renderer, and interactive playground.
- Added Python 3.12+ grammar, indentation-aware tokenizer, AST model, and web visualizer.
- Added WebGL 2D curve and 3D surface rendering to the Math Plotter demo with interactive orbit controls.
- Updated Dart grammar to full Dart 3 syntax (records, patterns, class modifiers) and added visualizer.
- Modernized example grammars to Dart 3 pattern matching, switch expressions, and modern combinators.
- Expanded automated test suites across all grammars, AST visitors, and CLI entry points.
- Numerous fixes, performance improvements, and refreshed web demos.

## 7.0.0

- Update to Dart 3.8 and PetitParser 7.0.
- Added Pascal, CSV example grammars.
- Numerous fixes and improvements.
- Better testing of grammars.

## 6.0.0

- Update to Dart 3.0 and PetitParser 6.0.
- Cleanup usage of deprecated code.
- Better test coverage.

## 5.4.0

- Upgrade to Dart 2.19 and PetitParser 5.4.
- Add BibTeX and RegExp examples.
- Add XML, XPath, and BibTeX demos.

## 5.1.0

- Dart 2.18 requirement.
- Cleanup the JSON and URL parsers to be fully typed.

## 5.0.0

- Dart 2.16 requirement.
- Cleaned up dynamic typing.
- Updates to latest version of PetitParser.
- Added a mathematical expression example.

## 4.4.0

- Initial version extracted from <https://github.com/petitparser/dart-petitparser>.
